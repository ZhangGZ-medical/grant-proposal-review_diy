# 临床前研究标书常见缺陷清单

## 一、科学设计层面

### 致命缺陷（直接导致不资助）
- [ ] 研究假设不可证伪（无法通过实验否定）
- [ ] 实验方案根本不可行（如需要10年造模周期）
- [ ] 缺少最基本的对照组（如药物研究无溶剂对照）
- [ ] 结局指标完全无法回答研究问题
- [ ] 方案存在不可逾越的伦理障碍

### 重大缺陷
- [ ] 假设过于宽泛（如"XX基因在肿瘤中发挥作用"），缺乏具体预测
- [ ] 关键技术超出课题组能力，且无合作方
- [ ] 阳性对照选择不当（如用已过时的标准治疗）
- [ ] 主要结局指标非领域主流，导致结果可比性差
- [ ] 研究设计类型与目标不匹配（如用横断面设计回答纵向变化问题）
- [ ] 未区分主要假设与探索性假设，"钓鱼式"研究

### 一般缺陷
- [ ] 假设推导逻辑链存在薄弱环节
- [ ] 动物模型与人类疾病对应关系讨论不足
- [ ] 预实验数据不足但声称"有基础"
- [ ] 受试对象（动物品系/性别/年龄）选择理由不充分
- [ ] 剂量选择依据不足（药效学研究中尤为常见）

## 二、统计学层面

### 致命缺陷
- [ ] 样本量严重不足（如 n=3 用于假设检验）
- [ ] 混淆生物学重复与技术重复
- [ ] 多重 t 检验完全未校正
- [ ] 统计方法根本错误（如分类资料用 t 检验）

### 重大缺陷
- [ ] 样本量无任何计算依据（仅写"每组6只"）
- [ ] 效应量设定无来源（凭空假设）
- [ ] 未设定脱落率，或脱落率估计不合理
- [ ] 多重比较校正方法不当（如 Bonferroni 过于保守但未选择替代方案）
- [ ] 缺失数据处理方案缺失
- [ ] 未区分主要分析和敏感性分析

### 一般缺陷
- [ ] 未说明正态性检验方案
- [ ] 统计软件未注明版本
- [ ] 亚组分析未预设（存在数据挖掘嫌疑）
- [ ] 未说明非劣效性/等效性界值依据（如适用）
- [ ] 样本量计算仅基于主要终点，未考虑次要终点

## 三、创新性与转化层面

### 致命缺陷
- [ ] 完全重复已有研究，无任何创新
- [ ] 声称的创新性已被他人发表
- [ ] 转化路径存在无法逾越的障碍（如靶点成药性已证伪）

### 重大缺陷
- [ ] 创新点表述空洞（"国内首次""系统研究"但无实质差异化）
- [ ] 忽视关键竞争研究（未引用领域最新突破）
- [ ] 转化前景过度夸大
- [ ] 技术壁垒被高估

### 一般缺陷
- [ ] 创新性仅在方法学层面，科学问题层面无创新
- [ ] 转化路线图不清晰
- [ ] 未讨论可替代技术方案
- [ ] 未展示独特资源优势

## 四、预算编制层面

### 重大缺陷
- [ ] 大额设备支出无必要性论证和三家比价
- [ ] 劳务费严重超标（超过依托单位规定标准）
- [ ] 预算总额与工作量明显不匹配
- [ ] 间接费用比例不合规

### 一般缺陷
- [ ] 部分科目比例偏离同类项目常规
- [ ] 差旅费/会议费无具体计划支撑
- [ ] 国际合作费无明确合作方和计划
- [ ] 预算说明过于简略

## 五、时间安排层面

### 重大缺陷
- [ ] 总体周期不可能完成所有任务
- [ ] 关键任务安排在与依赖任务之前（逻辑错误）
- [ ] 未考虑动物造模和伦理审批的固定时间

### 一般缺陷
- [ ] 里程碑不够量化
- [ ] 缺少 Go/No-Go 决策点
- [ ] 未识别关键路径
- [ ] 缓冲时间不足

## 六、撰写规范层面

### 重大缺陷
- [ ] 格式严重违规（如超出字数限制、字体/行距不合规）
- [ ] 大段抄袭（含自我抄袭）
- [ ] 关键引文缺失或完全过时
- [ ] 数据前后矛盾

### 一般缺陷
- [ ] 缩写首次出现未给出全称
- [ ] 术语前后不一致
- [ ] 引用格式不统一
- [ ] 图表分辨率低、图注不完整
- [ ] 段落逻辑跳跃
