# 临床前研究标书评分量表（锚定描述）

## 评分原则

- 每项 1--10 分（整数或 0.5 分粒度）
- 评分需基于标书文本中的具体证据
- 不确定时偏保守（取较低分）
- "N/A"表示标书中未涉及该子指标，计 0 分

---

## 维度 1：科学设计合理性（权重 25%）

### 1.1 研究假设明确性

| 分值 | 锚定描述 |
|------|----------|
| 10 | 假设表述精确、可证伪、有充分文献引用支撑，明确区分主要假设与探索性假设，附假设推导逻辑链 |
| 9 | 假设清晰可验证，文献支撑充分，区分了主次假设 |
| 8 | 假设清晰但部分推导逻辑需补充，文献支撑基本充分 |
| 7 | 假设基本清楚，但表述不够精炼，或个别逻辑环节跳跃 |
| 6 | 假设方向正确但缺乏具体预测值，可验证性存疑 |
| 5 | 假设过于宽泛（如"XX在YY中发挥重要作用"），难以具体验证 |
| 4 | 假设与立项依据逻辑链断裂，或与已有证据矛盾 |
| 3 | 假设含明显逻辑错误或与常识相悖 |
| 2 | 未提出可辨识的研究假设，仅为描述性研究目标 |
| 1 | 无假设表述，仅为现象描述或文献堆砌 |

### 1.2 实验方案可行性

| 分值 | 锚定描述 |
|------|----------|
| 10 | 每种关键实验均附详细方案（或引用已发表Protocol），预实验数据充分，动物模型选择有文献/预实验双重支持 |
| 9 | 关键实验方案详尽，有预实验数据，模型选择恰当 |
| 8 | 方案基本完整，预实验数据部分支撑，个别实验细节可补充 |
| 7 | 方案框架清晰但具体操作步骤不够详细，动物模型选择合理 |
| 6 | 方案存在技术难点未充分讨论，或关键步骤依赖未验证的新方法 |
| 5 | 部分关键实验方案明显缺失或不完整 |
| 4 | 技术路线存在不可行的关键环节（如难以获得的样本量/无法实现的检测） |
| 3 | 多个关键技术明显超出课题组能力范围且无合作方支撑 |
| 2 | 方案仅有概念性描述，无可操作的实验计划 |
| 1 | 方案明显不可行 |

### 1.3 对照组设置恰当性

| 分值 | 锚定描述 |
|------|----------|
| 10 | 阳性对照、阴性对照、假手术/溶剂对照、空白对照均齐全，考虑了批次效应、随机化、盲法 |
| 9 | 所有必要对照齐全，随机化和盲法有说明 |
| 8 | 主要对照齐全，个别辅助对照可补充 |
| 7 | 核心对照存在但不够完整（如缺少假手术组或溶剂对照组） |
| 6 | 仅设置了最基本的对照，缺少对潜在混杂的控制 |
| 5 | 对照组设置存在逻辑问题（如缺乏关键阳性对照） |
| 4 | 缺少必要的阴性对照或空白对照 |
| 3 | 对照组设置严重不足 |
| 2 | 几乎没有有效的对照设计 |
| 1 | 完全无对照组设计 |

### 1.4 结局指标合理性

| 分值 | 锚定描述 |
|------|----------|
| 10 | 主要终点与次要终点层次分明，指标均为领域公认金标准，替代终点与临床终点的关系有文献充分论证 |
| 9 | 主次要终点明确，指标为主流标准，替代终点合理性有文献支撑 |
| 8 | 结局指标合理但部分次要终点选择可优化 |
| 7 | 指标选择合理但未充分区分主次终点 |
| 6 | 核心指标尚可但缺少关键辅助指标 |
| 5 | 指标选择存在争议（非领域主流或敏感性不足） |
| 4 | 关键结局指标选择不当 |
| 3 | 指标无法有效回答研究假设 |
| 2 | 仅列出检测项目，未明确结局指标 |
| 1 | 无结局指标描述 |

### 1.5 研究设计类型匹配

| 分值 | 锚定描述 |
|------|----------|
| 10 | 研究设计（平行/交叉/析因/适应性等）与研究目标完美匹配，设计选择有充分理由 |
| 9 | 设计类型恰当，选择理由明确 |
| 8 | 设计基本合理但选择理由可更充分 |
| 7 | 设计可行但非最优选择 |
| 6 | 设计存在效率损失但尚可接受 |
| 5 | 设计类型与目标不匹配 |
| 4 | 设计有明显缺陷 |
| 3 | 未明确说明研究设计类型 |
| 2 | 设计混乱 |
| 1 | 无研究设计概念 |

## 维度 2：统计学方法适用性（权重 20%）

### 2.1 样本量计算依据

| 分值 | 锚定描述 |
|------|----------|
| 10 | 功效分析完整：明确效应量来源（预实验/文献Meta），α和1-β设定合理，脱落率预估有依据，不同终点分别计算后取最大值 |
| 9 | 功效分析完整，效应量来源清晰，考虑了脱落率 |
| 8 | 有功效分析但个别参数依据可加强（如效应量来源未注明） |
| 7 | 有样本量估算但仅基于经验公式，未做正式功效分析 |
| 6 | 样本量依据为"参考文献"但未给出具体数值计算 |
| 5 | 仅给出每组 n 值，无任何计算依据 |
| 4 | 样本量明显偏小（n<5/组）且无合理解释 |
| 3 | 样本量估计与实验设计不匹配（如未区分生物学重复与技术重复） |
| 2 | 仅提及"每组适量"，无具体数字 |
| 1 | 无任何样本量相关信息 |

### 2.2 统计方法选择

| 分值 | 锚定描述 |
|------|----------|
| 10 | 为每种分析指定具体统计方法及选择理由（含正态性/方差齐性检验方案），多重比较校正明确，区分了主要分析和敏感性分析 |
| 9 | 统计方法明确，选择合理，多重比较校正到位 |
| 8 | 方法基本合理但个别分析的方法选择可优化 |
| 7 | 方法选择合理但缺乏选择理由说明 |
| 6 | 方法大体正确但存在小问题（如未说明事后检验方法） |
| 5 | 方法选择存在不当之处（如对所有数据不加检验地使用参数检验） |
| 4 | 多重比较未校正 |
| 3 | 关键分析方法明显错误 |
| 2 | 统计方法描述极其模糊（如仅写"用SPSS分析"） |
| 1 | 无语统计方法描述 |

### 2.3 数据分析计划完整性

| 分值 | 锚定描述 |
|------|----------|
| 10 | 缺失数据处理方案（LOCF/MMRM/MI等）明确，亚组分析预先设定，协变量调整策略有依据，ITT/PP分析区分清晰 |
| 9 | 缺失数据处理有方案，亚组分析和协变量调整有预设 |
| 8 | 数据分析计划较完整，个别细节可补充 |
| 7 | 有基本分析计划但缺失数据处理策略不明确 |
| 6 | 分析计划过于简略 |
| 5 | 未提及缺失数据处理 |
| 4 | 分析计划存在漏洞 |
| 3 | 计划混乱，难以判断 |
| 2 | 几乎没有分析计划 |
| 1 | 无数据分析计划 |

### 2.4 统计软件与版本

| 分值 | 锚定描述 |
|------|----------|
| 10 | 注明统计软件/版本（如 SPSS 26.0, GraphPad Prism 9.0, R 4.3.0），自编代码附算法逻辑和参数设置 |
| 8 | 注明软件及版本 |
| 6 | 仅注明软件名称无版本 |
| 4 | 仅提及"使用统计软件分析" |
| 2 | 未提及统计软件 |

### 3.1 科学创新性

| 分值 | 锚定描述 |
|------|----------|
| 10 | 提出全新假说或概念框架，有理论推导和间接证据双支撑，可开辟新研究方向 |

| 8 | 有明确创新点，与现有研究差异化清晰 |

| 6 | 创新性表述较虚（如"首次系统研究"但无实质差异化） |

| 8 | 技术先进但非独有，竞争对手也可实现 |

| 2 | 技术描述模糊，无法判断 |

### 3.3 临床转化潜力

| 分值 | 锚定描述 |
|------|----------|

| 9 | 转化路径清晰，目标适应症明确，有商业前景分析 |
| 8 | 转化前景好但路径中个别环节需细化 |
| 7 | 有转化潜力但路径不够清晰 |

| 5 | 临床转化前景模糊 |

| 3 | 转化路径有严重障碍 |
| 2 | 转化前景明显为负 |
| 1 | 无任何转化相关讨论 |

### 3.4 研究独特性

| 分值 | 锚定描述 |
|------|----------|
| 10 | 拥有独特资源（特殊患者队列/独有转基因动物/独有化合物库/独有数据库），并在标书中明确展示其不可替代性 |
| 9 | 有独特资源且明确说明其优势 |
| 8 | 有一定独特优势但非不可替代 |

| 6 | 资源普通但实验设计有特色 |
| 5 | 无特殊资源或优势 |
| 4 | 未做竞争分析 |
| 3 | 忽略明显的竞争威胁 |
| 2 | 无任何独特之处 |
| 1 | 完全无差异化 |
