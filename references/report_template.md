## 附录：评分方法说明

- 每个子指标评分 1--10 分，详见 `references/scoring_rubric.md` 锚定描述
- 维度得分 = 该维度所有子指标的均值
- 加权总分 = Σ(维度得分 × 维度权重)
- 等级划分：优秀(≥9.0) / 良好(7.5--8.9) / 中等(6.0--7.4) / 较差(4.0--5.9) / 不合格(<4.0)
